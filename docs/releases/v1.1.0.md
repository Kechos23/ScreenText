# ScreenText 1.1.0

## Added

- Optional OpenAI Codex CLI connection alongside Direct and GitHub Copilot.
- Official Codex browser login, visible email/plan/workspace when available, account check and confirmed shared CLI logout.
- Dynamic paginated model catalog and independent extraction/translation defaults for Direct and CLI. Missing selections remain visible and unverified.
- Translation and mixed-language image extraction through ephemeral, tool-disabled Codex sessions. Account metadata is checked before requests; external changes require review.

## Setup

Install the official Codex CLI or a compatible desktop runtime. In Settings > AI Providers > OpenAI > Account, select Codex CLI - Use Codex on this PC, then Check connection or Sign in via Codex. Select Use for AI if another provider is active. No API key is required. Company policies still apply; this is not a guaranteed workaround for restricted accounts.

Direct and Copilot sign-ins are preserved. Codex CLI sign-in belongs to the Windows CLI environment, survives normal ScreenText restarts, and is not copied with the portable application. Logging it out affects other consumers of that shared local CLI login.

## Validation

Offline regression covers RPC login/account/catalog, explicit model routing, text/image requests, account/workspace changes, API-key refusal, failed/empty catalogs, cancellation, shared logout guards, preference isolation and dark/light UI previews. Separate live checks used only synthetic text/images and confirmed translation plus mixed Greek/English extraction with Luna. No real login/logout was performed during automated regression.

Windows x64 portable ZIP and SHA256SUMS.txt are identical on GitHub and Gitea. Binaries remain unsigned. OneOCR and provider availability retain the limitations documented in README.
