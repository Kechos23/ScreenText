# ScreenText 1.0.0

First public release of ScreenText for Windows x64.

- Region capture with configurable global shortcut and right-click/Esc cancellation.
- Automatic local OneOCR plus explicit Windows OCR fallback/language management.
- Independent ChatGPT-plan connection and official GitHub Copilot CLI/SDK integration.
- Explicit active provider, visible account, separate extraction/translation models and dynamic catalogs.
- Editable source/results, expanded reading views, retained previous translations and source/target change indicators.
- Temporary captures by default, optional automatic saving, image copy and external editor support.
- Dark/light modes, six accents, tray controls and optional Windows startup.
- Versioned portable packaging, dependency integrity checks, MIT source license and third-party notices.

## Compatibility

Requires Windows 10/11 x64, .NET Framework 4.8 and Windows PowerShell 5.1. Copilot follows official CLI requirements, including PowerShell 7 on Windows. The private Node/CLI/SDK runtime is included; no global installation is needed. AI usage uses the chosen provider's plan, not a separately configured model API key.

Automatic OneOCR is an unofficial Snipping Tool integration and may change after Windows updates. Windows OCR needs installed language packs. The ChatGPT plan route is experimental. Copilot Enterprise Cloud support requires administrator permission and validation in your managed environment; public-account testing is not enterprise certification. ScreenText is not code-signed.

Download `ScreenText-1.0.0-win-x64.zip`, extract the complete folder and run `ScreenText.exe`. Verify against `SHA256SUMS.txt`. User settings and credentials are not included in the release.
